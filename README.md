O objetivo desta atividade é consolidar e avaliar os conhecimentos adquiridos em Python(Spyder),GitBash,GitHub,Vim e SSH/SCP.
As ferramentas utilizadas foram Python(Spyder),GitBash,GitHub,Vim e SSH/SCP.
O programa deve ser executado dentro da pasta onde estão armazenados os ficheiros a serem analisados.
O teste.py foi criado mas tive que repor o repositório a dada altura.
As respostas da tarefa 3 encontram-se no organizador.py como comentário.
Inicializar um repositório local serve para preparar uma área de transferência local. É a porta de saída dos ficheiros a serem tranferidos.
O comando git status serve para nos mostrar o que está no repositório.


Respostas:

git -add serve para adicionar ficheiros à publicação, quase como se fosse uma área de transferência

git -commit grava no histórico do repositório local a área de transferência

git log --oneline apresenta o histórico de commit

commit grava apenas no local. push envia para a nuvem, neste caso, o GitHub.
